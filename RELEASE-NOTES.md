# Quranly PC 0.5.0 for Windows

Download **Quranly-Setup-0.5.0-x64.exe** for standalone installation, or use **quranly-0.5.0-win-x64.zip** with BlueCloud Launcher.

Quran reading, reciter collections, persistent offline audio downloads, local quality options and optional account backup.

Existing app identifiers, settings and downloaded content are retained. Windows x64 preview; installers are unsigned. Corresponding source, app metadata and SHA-256 checksums are included.

# Quranly PC 0.6.0 for Windows

Download **Quranly-Setup-0.6.0-x64.exe**, or use **quranly-0.6.0-win-x64.zip** with BlueCloud Launcher.

- Offline audio is committed together with its library entry. Interrupted downloads, non-audio responses and storage failures no longer report a completed download.
- Downloads can check for missing offline files and download them again. Existing cached audio remains compatible.
- Playback position saves when audio pauses or the window closes.
- Reading and memorization use a single account-scoped checkpoint. Storage failures show a recovery message instead of silently losing progress.
- Reproducible desktop builds retain the existing public Supabase configuration. Private provider keys are excluded.

Unit, desktop UI and packaged application checks cover offline repair, reading progress, saved preferences and collection downloads. Existing identifiers, profiles and downloaded content are retained. Windows x64 preview; unsigned until a certificate is connected. Source and checksums are included.
